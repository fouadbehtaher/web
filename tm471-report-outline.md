# TM471 Report Outline

## Suggested report title

Design and Implementation of an AI-Based Web Application Firewall

## Suggested structure

### Abstract

Briefly explain the problem, the proposed AI-based WAF, the implementation approach, and the main evaluation results.

### Chapter 1: Introduction

- Background of web application security
- Motivation for using AI in WAF systems
- Project aim
- Project objectives
- Scope and limitations
- Report structure

### Chapter 2: Literature Review and Background

- Overview of web application attacks
- Traditional Web Application Firewalls
- Signature-based vs anomaly-based detection
- Machine learning in cybersecurity
- Related work on intelligent intrusion detection and WAF systems

### Chapter 3: Requirements and Analysis

- Functional requirements
- Non-functional requirements
- Threat model
- System use cases
- Expected inputs, outputs, and constraints

### Chapter 4: System Design

- Overall architecture
- Traffic flow through the WAF
- Feature extraction design
- AI model selection
- Decision engine
- Logging and alerting design

### Chapter 5: Implementation

- Development environment
- Dataset preparation
- Request preprocessing
- Model training and testing
- WAF prototype implementation
- Integration with sample web application

### Chapter 6: Testing and Evaluation

- Test scenarios
- Attack categories used in evaluation
- Accuracy, precision, recall, F1-score
- False positives and false negatives
- Response time / latency impact
- Discussion of results

### Chapter 7: Project Management and Reflection

- Project plan and milestones
- Risks and mitigation
- Challenges faced
- Ethical and security considerations
- Lessons learned

### Chapter 8: Conclusion and Future Work

- Summary of achievements
- Main findings
- Limitations
- Future improvements such as online learning, adaptive rule generation, and explainable AI

### References

Use a consistent academic citation style required by your university.

### Appendices

- Sample attack payloads
- Screenshots of the prototype
- Dataset samples
- Test results tables
- Source code snippets if required

## Notes for this project

- Keep the scope realistic for a graduation project.
- Focus on a working prototype, not a production-grade enterprise WAF.
- It is better to demonstrate strong evaluation on a smaller set of attack classes than to claim full protection against all web threats.
